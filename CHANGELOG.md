# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — [SemVer](https://semver.org/lang/ru/).

## [Unreleased]

### Removed
- `DSH-Web.command`: запуск веб-интерфейса вынесен из репозитория в отдельное
  приложение macOS. Из терминала — `npx @deepseek-ai/dsh web`.

## [0.3.0] — 2026-09-22

### Added
- Релизный workflow GitHub Actions (`.github/workflows/release.yml`): по пушу
  тега `vX.Y.Z` собирает бинарники под Linux x86_64 и macOS arm64, проверяет
  совпадение тега с `WW_VERSION_STRING`, прогоняет тесты и санитайзеры и
  публикует GitHub Release с описанием из этого файла.

### Changed
- Выход из приложения перенесён с `Ctrl+Q` на `Ctrl+C` (привычная комбинация;
  в raw-режиме `ISIG` отключён, поэтому она приходит байтом `0x03`, а не
  сигналом).

### Fixed
- `format-check` в CI: версия `clang-format` зафиксирована на 21.x. Версия
  18.x из apt на `ubuntu-latest` считает ширину строк в байтах и отвергала
  выравнивание хвостовых кириллических комментариев, корректное для 21.x.

## [0.2.0] — 2026-09-19

### Added
- Опции командной строки `--help` / `--version`.
- Завершение работы по `Ctrl+Q` с выводом итоговой сводки (ранее в
  raw-режиме выйти можно было только внешним сигналом).
- Строка-подсказка по управлению в интерфейсе.
- Распознавание X10-отчётов мыши (терминалы без поддержки SGR-режима):
  отпускание и прокрутка больше не дают ложных переключений.
- Проверка, что stdin — терминал; понятное сообщение об ошибке иначе.
- Обработка `SIGHUP` с восстановлением терминала.
- Юнит-тесты (`make test`) для `input`, `tracker`, `ui`, `clock`, `status`.
- Цели `make sanitize`, `format`, `format-check`, `lint`, `check`, `help`.
- Конфигурации `.clang-format`, `.clang-tidy`, `.editorconfig`,
  `.gitattributes`; CI на GitHub Actions (Linux gcc/clang, macOS).
- Документация: `CONTRIBUTING.md`, `docs/ARCHITECTURE.md`.

### Changed
- Репозиторий реорганизован: `include/workwatcher/`, `src/`, `tests/`,
  `scripts/`, `docs/`; сборка ведётся в `build/`.
- Единый префикс `ww_` / `WW_` для публичных идентификаторов.
- Модуль `timer` разделён на `clock` (источники времени) и `tracker`
  (накопление по режимам); состояние «стабильных часов» стало явным
  (`ww_stable_clock_t`) вместо скрытого глобального.
- Разбор ввода вынесен из `terminal` в чистый модуль `input`.
- Функции форматирования `ui` стали публичными и тестируемыми; момент
  «сейчас» передаётся параметром.
- Ошибки терминала возвращаются как `ww_status_t` с текстовым описанием.
- Параметры (длительность рабочего дня, период обновления) собраны в
  `config.h` и переопределяются флагами компилятора.
- Расширен набор предупреждений компилятора; сборка чиста с `-Werror`.
- `run.sh` перенесён в `scripts/`, `WorkWatcher.command` обновлён.
- `.vscode` настроен на сборку через `make`; `.idea` исключён из
  репозитория.

### Fixed
- Восстановление терминала из обработчика сигнала могло зависнуть:
  `tcsetattr(TCSAFLUSH)` ждал, пока терминал заберёт весь вывод. Теперь
  используется `tcflush(TCIFLUSH)` + `tcsetattr(TCSANOW)`.

### Removed
- Собранный бинарник `workwatcher` из репозитория.

## [0.1.0] — 2026-09-18

### Added
- Учёт времени в режимах «Работа» и «Дом», переключение любой клавишей
  или кнопкой мыши.
- Расчёт времени окончания рабочего дня, устойчивый к переводу системных
  часов.
- Отрисовка без мерцания; восстановление терминала по сигналам.
