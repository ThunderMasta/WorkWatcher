# WorkWatcher
Консольное приложение на C для измерения времени.

## Сборка и запуск

Быстрый способ — готовый скрипт (собирает и сразу запускает):

```sh
./run.sh
```

Или вручную:

```sh
make
./workwatcher
```

Опции `run.sh`:

```sh
./run.sh --clean   # очистить и собрать заново
./run.sh --debug   # отладочная сборка (-g -O0)
./run.sh --help    # справка
```

На старых системах Linux может потребоваться `-lrt` (для `clock_gettime`):

```sh
make LDLIBS=-lrt
```

## Управление

Приложение по очереди ведёт фазы **Работа** и **Дом**. Нажатие любой клавиши

завершает текущую фазу и переключает на следующую. Переключение также
срабатывает по нажатию кнопки мыши (отпускание кнопки, прокрутка и движение
мыши игнорируются).

## Структура

| Файл         | Ответственность                                |
|--------------|------------------------------------------------|
| `main.c`     | точка входа, цикл фаз                          |
| `terminal.*` | raw-режим терминала, ввод с таймаутом, сигналы |
| `timer.*`    | накопление времени, монотонные часы            |
| `ui.*`       | форматирование и отрисовка кадра               |
