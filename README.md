# WorkWatcher

[![CI](https://github.com/ThunderMasta/WorkWatcher/actions/workflows/ci.yml/badge.svg)](https://github.com/ThunderMasta/WorkWatcher/actions/workflows/ci.yml)

Консольное приложение на C11 для учёта времени в двух режимах — **Работа** и
**Дом**. Показывает накопленное время по каждому режиму и расчётное время
окончания рабочего дня (8 часов по умолчанию).

```
Работа: 03:12:45 - Дом: 00:41:10
Работа закончится: 17:48:05
Любая клавиша или кнопка мыши — сменить режим, Ctrl+Q — выход
```

## Возможности

- Переключение режима любой клавишей или нажатием кнопки мыши
  (отпускание кнопки, прокрутка и движение мыши игнорируются).
- Устойчивость к ручному переводу системных часов: длительности считаются
  по монотонным часам, время окончания — по «стабильным» настенным часам.
- Без мерцания: кадр перерисовывается поверх предыдущего.
- Корректное восстановление терминала при выходе, `SIGINT`/`SIGTERM`/`SIGHUP`.
- Нет внешних зависимостей: только libc и POSIX.

## Требования

- POSIX-совместимая ОС (macOS, Linux).
- Компилятор C11 (`clang` или `gcc`) и `make`.
- Опционально для разработки: `clang-format`, `clang-tidy`.

## Быстрый старт

```sh
make            # сборка → build/workwatcher
make run        # сборка и запуск
```

Или через скрипт (собирает и сразу запускает):

```sh
scripts/run.sh            # release
scripts/run.sh --debug    # отладочная сборка
scripts/run.sh --clean    # пересобрать с нуля
```

На macOS можно запустить двойным щелчком по `WorkWatcher.command` в Finder.

### Опции командной строки

```
workwatcher [--help] [--version]
```

### Управление

| Действие                     | Результат                          |
|------------------------------|------------------------------------|
| Любая клавиша / кнопка мыши  | Завершить фазу и сменить режим     |
| `Ctrl+Q`                     | Завершить работу и вывести сводку  |

Cmd+Q на macOS перехватывается самим приложением терминала и закрывает его
окно; WorkWatcher при этом получает `SIGHUP`, корректно восстанавливает
терминал и завершается, но сводку показать уже не успевает.

## Сборка и проверки

| Команда              | Описание                                                  |
|----------------------|-----------------------------------------------------------|
| `make`               | Release-сборка (`-O2`)                                    |
| `make debug`         | Отладочная сборка (`-O0 -g3`)                             |
| `make test`          | Юнит-тесты                                                |
| `make sanitize`      | Тесты под AddressSanitizer + UndefinedBehaviorSanitizer   |
| `make format`        | Отформатировать код (`clang-format`)                      |
| `make format-check`  | Проверить форматирование                                  |
| `make lint`          | Статический анализ (`clang-tidy`)                         |
| `make check`         | Всё вместе: `-Werror`, тесты, санитайзеры, формат         |
| `make clean`         | Удалить `build/`                                          |
| `make help`          | Список целей                                              |

Переменные: `BUILD_TYPE=release|debug`, `SANITIZE=1`, `WERROR=1`, `CC=clang`,
`V=1` (подробный вывод).

Параметры приложения (длительность рабочего дня, период обновления и т. п.)
задаются в `include/workwatcher/config.h` и могут быть переопределены при
сборке:

```sh
make CPPFLAGS+='-DWW_WORKDAY_SECONDS=27000'   # 7,5-часовой день
```

На старых Linux может потребоваться `-lrt` для `clock_gettime`:

```sh
make LDLIBS=-lrt
```

## Структура репозитория

```
.
├── include/workwatcher/   публичные заголовки модулей
├── src/                   реализация
├── tests/                 юнит-тесты (собственный мини-каркас, без зависимостей)
├── scripts/               вспомогательные скрипты
├── docs/                  документация (архитектура)
├── .github/workflows/     CI: сборка, тесты, санитайзеры, формат, линтер
├── Makefile
└── WorkWatcher.command    запуск из Finder (macOS)
```

| Модуль       | Ответственность                                               |
|--------------|---------------------------------------------------------------|
| `config`     | Константы времени компиляции                                  |
| `status`     | Коды результата и их описания                                 |
| `clock`      | Монотонные, настенные и «стабильные» часы                     |
| `tracker`    | Накопление времени по режимам (чистая логика)                 |
| `input`      | Разбор сырого ввода в события: TOGGLE / QUIT / NONE (чистый)  |
| `terminal`   | Raw-режим, отчёты мыши, чтение с таймаутом, сигналы           |
| `ui`         | Форматирование строк (чистое) и отрисовка кадра               |
| `app`        | Главный цикл фаз                                              |
| `main`       | Аргументы командной строки и жизненный цикл терминала          |

Подробнее: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
